# Instrucciones del proyecto

Proyecto de aprendizaje: fullstack mínimo para entender las piezas (frontend, backend, base de datos) y cómo se conectan, no para aprender a programar en profundidad.

## Alcance
- Web básica con formulario y listado de productos tecnológicos. CRUD completo: crear, listar, editar, borrar.
- Producto: nombre, marca, categoría, precio, stock, descripción.
- Sin autenticación. Todo en local. Sin Git por ahora.

## Stack
- Frontend: HTML, JS (vanilla) y CSS3.
- Backend: NestJS.
- Base de datos: MongoDB instalado en local (sin Docker), con Mongoose.

## Orden de fases (lo pide el profesor)
1. Frontend simple, sin backend. Los datos viven en el navegador.
2. Añadir backend NestJS y conectar el frontend. Datos en memoria del servidor.
3. Añadir MongoDB para que los datos se guarden de verdad.

## Forma de trabajar (obligatorio)
- Antes de cualquier paso, mostrar qué se va a hacer y esperar aprobación explícita.
- Preguntar siempre ante cualquier duda. No asumir. Tomarse el tiempo necesario.
- Avanzar en pasos pequeños, uno cada vez.
- Nivel con terminal, Node y npm: bajo. Explicar cada comando y cada pieza en lenguaje sencillo, con el porqué.
- Respuestas en español, directas y con viñetas o tablas.
- El coding se hace en Claude Code desde la terminal. El proyecto lleva un CLAUDE.md con estas reglas.
